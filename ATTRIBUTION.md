# Mermaider: attribution and publication status

Mermaider is maintained and developed by Jakob Endemann. The application's Git
history also contains earlier application contributions by Dario Novoa Vergara
and an Appwrite deployment/template contribution. Renaming the project and
changing its design do not erase those contributions.

| Contributor | Evidence and scope |
| --- | --- |
| Jakob Endemann | Mermaider development from 2026: cross-platform configuration, monochrome design system, workspace and provider features, diagram editing improvements, release stabilization and product website. Representative commits: `e0d9b59`, `5e4f6e5`, `2c59fb3`, `a65c470`, `8452be7`. |
| Dario Novoa Vergara | Original Mermalaid React/Tauri application and earlier Mermaid editor features, including the initial visual editor. Representative commits: `ca436da`, `4dcc633`, `4d46bfb`. |
| Appwrite | Deployment/template integration and MIT license text carrying the existing `Copyright (c) 2024 Appwrite` notice. Commit `a5cbe7e`. |
| Dependency maintainers | Mermaid, Monaco, React, Tauri and other installed dependencies retain their own licenses and notices. A project license does not replace dependency licenses. |

These descriptions are based on repository evidence, not a declaration of sole
ownership or an inferred transfer of rights. The current metadata requests MIT
for Mermaider. Earlier contributions were recorded with CC BY-NC-SA 4.0 before
an Appwrite commit replaced LICENSE with MIT. On 2026-10-02 the project owner explicitly confirmed that MIT permission for
the inherited Dario Novoa contributions is available. This is a reported grant;
the underlying permission document was not independently inspected. See the detailed
[provenance review](docs/SOURCE_PROVENANCE.md).

On 2026-10-04 the project owner confirmed successful practical acceptance on
Windows and macOS and explicitly authorized public MIT repository/installer
distribution. Actual publication and upload status are tracked in
[the publication handoff](docs/PUBLICATION_1.8.7.md). Existing
foreign notices and Git history are retained. No history rewrite was performed.

2.7.0, MIT, Copyright (c) 2026 Alain. The requested `@blobatar` shadcn registry is
registered in package.json; the React adapter preserves the existing CSS design
without importing a separate UI framework. Original license text is distributed
at [public/website/blobatar-license.txt](public/website/blobatar-license.txt).
