# Mindmap

Mindmaps are an excellent way to organize information visually.

## Syntax Example

\`\`\`mermaid
mindmap
  root((mindmap))
    Out of box shaping
      node
      round-square
      circle
    Default shape
      [Square]
    Shapes
      (Rounded rectangle)
\`\`\`

## Node Shapes
* \`((circle))\`
* \`[square]\`
* \`(rounded rectangle)\`
* \`{{hexagon}}\`
* \`((bang))\`
* \`[\\trapezoid/]\`
