# C4 Diagram

Mermaid's C4 diagram integration lets you create architecture diagrams using the C4 model.

## Syntax Example

\`\`\`mermaid
C4Context
  title System Context diagram for Internet Banking System
  Person(customerA, "Banking Customer", "A customer of the bank.")
  System(SystemAA, "Internet Banking System", "Allows customers to view information and make payments.")
  
  Rel(customerA, SystemAA, "Uses")
\`\`\`

## Features
* Supports Context, Container, Component, and Dynamic diagrams.
* Use \`Person\`, \`System\`, \`System_Ext\` to define entities.
* Use \`Rel(from, to, description)\` to draw connections.
