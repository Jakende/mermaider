# Timeline

Timeline diagrams are helpful to chart out historical events or a chronology of steps.

## Syntax Example

\`\`\`mermaid
timeline
    title History of Social Media Platform
    2002 : LinkedIn
    2004 : Facebook
         : Google
    2005 : Youtube
    2006 : Twitter
\`\`\`

## Structure
* Use \`timeline\` to denote the diagram type.
* \`title\` adds a header to the diagram.
* Specify a period/date followed by a colon \`:\` and the event.
* Multiple events can be assigned to the same period by using empty periods (just spaces followed by \`:\`).
